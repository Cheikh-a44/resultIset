Corriger le nom d'une matière

Remplace l'ancien nom d'une matière importée par le nom du module, pour tous les étudiants du semestre (TP, CC, Examen... inclus).

Importer la structure (Excel)

Crée d'un coup tous les modules et matières depuis un fichier Excel. Colonnes : Departement | Semestre | Code module | Nom module | Matiere | Credits | TP (Oui/Non) — une ligne par matière. Les modules du fichier sont écrasés ; les autres ne sont pas touchés.

Générer credits.js

Lit tous les modules enregistrés (tous les départements et semestres) et télécharge un fichier credits.js complet. Les crédits déjà présents sont conservés ; les nouvelles matières reçoivent 3 crédits (ou la valeur saisie dans « Crédits »). Modifiez ensuite les valeurs à la main si besoin.
